# Screenshots Directory

This directory is reserved for screenshots of the running Security Log Analyser application.

## How to Capture Genuine Screenshots:
1. Launch the application locally:
   ```powershell
   streamlit run app.py
   ```
2. In your browser (at `http://localhost:8501`), select **Demo Mode (Synthetic Logs)**.
3. Capture the following recommended views:
   - `dashboard_overview.png`: Full dashboard displaying KPI summary cards, timeline, and distribution charts.
   - `security_alerts_triage.png`: Detailed security alerts table with severity badges and plain-English evidence expanders.
   - `forensic_investigation.png`: Event investigation table with search and filtering active.
   - `export_reporting.png`: Export buttons and executive summary generation.
4. Save the captured PNG files in this `docs/screenshots/` folder and link them in the project `README.md`.
